# Инструкции для водителей

Мобильный веб-дашборд: водитель открывает одну ссылку, находит нужную тему и читает/смотрит инструкцию прямо в приложении. Файлы остаются на Google Диске — здесь только удобная витрина.

## Как добавить новую инструкцию

Три шага, без программирования.

**1. Залей файл на Google Диск** (в любую папку).

**2. Открой доступ по ссылке.** Правый клик по файлу → «Открыть доступ» → «Все, у кого есть ссылка» → роль **Читатель**. Скопируй ссылку.

> ⚠️ Без этого шага файл не откроется внутри приложения — водитель увидит пустой экран.

**3. Добавь строку в [`data/instructions.json`](data/instructions.json).** Проще всего прямо на GitHub: открой файл → карандаш ✏️ → впиши блок в массив `items` → Commit. Через минуту сайт обновится сам.

```json
{
  "id": "unikalnyy-id",
  "category": "tacho",
  "subtopic": "Основы",
  "title": "Название инструкции",
  "description": "Короткое пояснение, о чём это",
  "type": "pdf",
  "url": "https://drive.google.com/file/d/АЙДИ_ФАЙЛА/view?usp=sharing",
  "updated": "2026-07-15",
  "tags": ["ключевое слово", "ещё одно"]
}
```

> 📌 Если инструкция критически важная (штраф, запрет, безопасность) и её
> обязательно должны увидеть все водители сразу — добавь `"important": true`.
> Она попадёт в красный блок «❗ Важно» на самом верху главной страницы.

### ID категорий

В поле `category` пиши **id**, а не название:

| `category` | Категория |
|---|---|
| `tolls` | 🛣️ Оплата дорог и боксы |
| `dtp` | 🚨 ДТП |
| `docs` | 📋 Документы и отчёты |
| `fuel` | ⛽ Топливо |
| `tacho` | ⏱️ ТАХО и режим труда |
| `truck` | 🚛 Работа с техникой |
| `loading` | 📦 Погрузка и разгрузка |
| `safety` | 🦺 Безопасность |
| `rules` | 📌 Правила компании |
| `video` | 🎬 Видео инструкции |

### Поля

| Поле | Обяз. | Что это |
|---|---|---|
| `id` | да | Уникальный, латиницей. Попадает в ссылку: `#/item/unikalnyy-id` |
| `category` | да | `id` категории из массива `categories` ниже в этом же файле |
| `subtopic` | нет | Подзаголовок внутри категории. Пусто — карточка просто в общем списке |
| `title` | да | Название на карточке |
| `description` | нет | 1–2 строки под названием |
| `type` | да | `pdf`, `doc`, `sheet`, `slide`, `image`, `video`, `link` — от него зависят цвет иконки и способ показа |
| `url` | да | Ссылка с Диска как есть, ничего переделывать не нужно |
| `updated` | нет | Дата в формате `ГГГГ-ММ-ДД` |
| `tags` | нет | Слова для поиска, которых нет в названии |
| `important` | нет | `true` — критично важное. Карточка попадает в красный блок «❗ Важно» на самом верху главной страницы (до «Недавних» и категорий) и подсвечивается красным везде. Убери флаг (или поставь `false`), когда актуальность прошла |

### Добавить категорию

Одна строка в массив `categories`. `order` задаёт порядок плиток на главной.

```json
{ "id": "border", "title": "Границы и таможня", "icon": "🛃", "order": 9 }
```

### Подтемы внутри категории

Подтема появляется сама, как только у карточки заполнено поле `subtopic`. Чтобы задать **порядок** подтем, перечисли их в категории — как сделано у «Видео инструкций»:

```json
{
  "id": "video",
  "title": "Видео инструкции",
  "icon": "🎬",
  "order": 8,
  "subtopics": [
    "Работа с дорожными боксами",
    "Лайфхаки с телефоном",
    "Техника безопасности"
  ]
}
```

Правила простые:

- Подтема из списка, в которой пока нет файлов, **не показывается** — появится с первым файлом.
- Подтема, которой нет в списке, тоже работает — просто встанет в конец.
- Карточки без `subtopic` всегда идут сверху категории.
- `subtopics` можно добавить в **любую** категорию, не только в видео.

### Переименовать подтему

Поправь текст в `subtopics` **и** в поле `subtopic` у карточек — они должны совпадать буква в букву.

### Переименовать категорию

Меняй `title` сколько угодно. А вот `id` лучше не трогать: на него ссылаются карточки через `category`, и он попадает в ссылки.

### Удалить

Удали нужный блок в `items`. Ничего больше трогать не надо.

## Как править гид по инструктажу

Отдельный раздел для новых водителей — крупный баннер «Вводный инструктаж» на главной. Содержимое лежит в [`data/guide.json`](data/guide.json), правится так же, как обычные инструкции: открой файл на GitHub → карандаш ✏️ → правь → Commit.

Структура: блоки → шаги. Каждый шаг может ссылаться на 0 или несколько уже существующих карточек из `instructions.json` (по `id`, тому же самому, что и в остальном каталоге).

```json
{
  "id": "phone-whatsapp",
  "title": "Связь с офисом",
  "text": [
    "Первый абзац на «Вы»…",
    "Второй абзац, если нужен…"
  ],
  "items": ["rules-nl-merwedebrug"],
  "confirm": "Понятно"
}
```

| Поле | Обяз. | Что это |
|---|---|---|
| `id` | да | Уникальный, латиницей. Не переименовывать без нужды — на него ссылается сохранённый прогресс водителей |
| `title` | да | Заголовок шага |
| `text` | да | Массив абзацев — каждая строка своим абзацем. Обращение на «Вы» |
| `items` | нет | Список `id` существующих карточек из `instructions.json`. Опечатка не ломает шаг — просто покажет «Материал недоступен» вместо ссылки |
| `confirm` | нет | Если задано — на шаге появляется чекбокс с этим текстом, отметка сохраняет прогресс |

Блок — это просто группа шагов: `{ "id": "...", "title": "...", "icon": "🎓", "steps": [...] }`. Порядок блоков и шагов = порядок прохождения.

**Проверить перед сохранением**, что все `items` действительно существуют в `instructions.json` — глазами или через `node --check`/`JSON.parse` (см. `CLAUDE.md`). Автоматической сверки между двумя файлами нет.

## Локальный просмотр

```powershell
.\serve.ps1
```

Откроется на `http://localhost:8000`. Сервер нужен потому, что страница читает JSON через `fetch()`, а из `file://` браузер это запрещает.

## Публикация

GitHub Pages, ветка `main`, папка `/` (root). Каждый коммит автоматически обновляет сайт. Бесплатно.

Водителю можно дать ссылку сразу на конкретную инструкцию: `…/#/item/tacho-basics`.

## Как это устроено

| Файл | Назначение |
|---|---|
| `index.html` | Каркас: шапка, поиск, контейнер, модалка просмотра, баннер и оверлей гида |
| `data/instructions.json` | **Всё содержимое каталога.** Основной файл для наполнения |
| `data/guide.json` | Содержимое гида по инструктажу — отдельный файл, см. выше |
| `assets/js/app.js` | Загрузка данных, hash-роутинг, рендер экранов, поиск |
| `assets/js/guide.js` | Пошаговый гид по инструктажу |
| `assets/js/drive.js` | Превращает ссылку Диска в URL для встроенного просмотра |
| `assets/js/store.js` | «Недавние» через localStorage |
| `assets/css/styles.css` | Мобильный дизайн, тёмная тема |

Ни сборки, ни зависимостей, ни npm — чистые HTML/CSS/JS. Открывается и правится где угодно.

## Установка на телефон

Открыть ссылку → меню браузера → «Добавить на главный экран». Появится иконка, приложение откроется без адресной строки.
